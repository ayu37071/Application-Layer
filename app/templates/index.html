⚖️ TCP vs. UDP Architectural Comparison Reference Table
Property TCP (Transmission Control Protocol) UDP (User Datagram Protocol)
Connection Connection-oriented (3-way handshake required) Connectionless (fire-and-forget datagrams)
Reliability Guaranteed in-order delivery via ACKs & retransmissions Unreliable (packets can drop, duplicate, or reorder)
Ordering Strict byte-stream sequencing via 32-bit SEQ numbers No sequence tracking; datagram boundaries preserved
Flow & Congestion Advertised Window (flow) + cwnd (congestion control) None (application must throttle itself)
Header Overhead 20 to 60 bytes Minimal 8 bytes
Use Cases HTTP/1.1, HTTP/2, SMTP, SSH, File Transfers DNS queries, VoIP, live multiplayer gaming, DHCP
🚀 QUIC & HTTP/3 Overview Modern Evolution

QUIC (RFC 9000) operates on top of UDP to overcome TCP limitations:

  • 0-RTT Connection Establishment: Merges transport and TLS 1.3 cryptographic handshakes into a single round-trip.
  • No Head-of-Line (HoL) Blocking: Multiple HTTP streams are independently multiplexed. Dropping a packet in Stream 1 does NOT stall Stream 2!
  • Connection Migration: Connections are identified by a 64-bit Connection ID rather than the 4-tuple (IP:Port), allowing seamless switching between Wi-Fi and 5G cellular.
